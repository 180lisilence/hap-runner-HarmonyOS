Android 宿主 ArkUI-X 命令行打包 com.haprunner 1.1.0

HAP Runner for HarmonyOS

在安卓手机上选择、解析、解包并运行 HarmonyOS 的 .hap 应用，页面经 ArkUI-X 运行时渲染。个人学习项目，与官方无关。

查看源码 关联示例应用

核心特性

选择与扫描

手动挑选 .hap 文件，或扫描本地存储与已授权目录树；支持从文件管理器「打开方式」直接送入。

HAP 解析

读取 module.json，判断应用模型与兼容级别，定位主 EntryAbility，生成实例名、摘要与 SHA-256。

解包装配

将 HAP 条目解包成 ArkUI-X 的 assets/arkui-x/<module> 目录结构，交给运行时加载。

运行时探测

检测方舟引擎 .so、Java 适配层与宿主 Activity 是否齐备；缺失时给出精确的缺项提示。

一键命令行打包

aapt2 → javac → d8 → 资源/原生库/assets 拼装 → zipalign → apksigner，无需 Android Studio。

两种构建形态

不带运行时的精简版（仅解析/解包），或接入 ArkUI-X 运行时的完整版（可真正渲染 ArkTS 页面）。

快速构建

# 普通构建（不含 ArkUI-X 运行时，仅解析 / 解包）
.\build.ps1

# 带 ArkUI-X 运行时构建，并安装到已连接设备
.\build.ps1 -ArkuiXSdk "<ArkUI-X SDK 根目录>" -Install

# 探测本机运行时是否齐备
.\build.ps1 -Probe
